# Journals v0.3.3 (preview)

Journals opens or creates today's Markdown journal in the current Eidos Lite Space. Its overview adds a yearly writing heatmap, streaks, day counts, and recent entries. Journal contents stay local; the overview receives file paths and non-empty line counts.

This release requires an Eidos Lite development build with plugin API 1.5.0 or later. It is not compatible with the published Eidos Lite 0.17.0 or CLI Serve.

Download `eidos.journals-0.3.3.eidos-plugin` and its `.sha256` file below. Install the package through **Plugins → Install plugin…** in a compatible Lite build, then enable Journals in your Space.
