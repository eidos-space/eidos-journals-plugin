# Journals 0.5.3

- Fix permission errors when creating a missing journal from the overview's Today's journal shortcut. The overview now declares the write access required by that operation. Existing journals open without being overwritten.
- Tighten the phone layout: the Today row shares space with refresh, statistics use compact inline values, and section spacing leaves more room for the activity chart and recent entries.

On mobile, enable Journals again in each Space after updating. Requires Plugin API 3.0.0 and Eidos Lite 0.20.0 or later. Current Android and iOS mobile host builds are supported; CLI Serve is not supported.
